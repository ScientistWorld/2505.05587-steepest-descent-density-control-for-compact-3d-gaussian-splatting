# Scientist Constraints

## Data

Use only the deterministic scenes generated by `data/synthetic_gaussian_scene.py` for the local benchmark. Do not add external images, scenes, pretrained radiance fields, or extra supervised samples for `compact_synthetic_splatting_seed7` or `compact_synthetic_splatting_seed13`.

## Evaluation Budget

Use the same train/test sample counts and the same maximum training steps as the provided scripts unless a new experiment name is added. Increasing samples, iterations, or the maximum primitive budget is resource scaling and must not be compared under the same score key.

## Output Contract

The evaluated method must write predictions and metadata in the same `outputs/<run>/predictions.npz` and `outputs/<run>/metrics.json` format consumed by `scripts/evaluate.sh`.

## Compliance Checklist

- [ ] Uses only the provided procedural benchmark data.
- [ ] Does not train longer or use more samples under the same experiment key.
- [ ] Reports final primitive count and prediction artifacts consumed by the shared evaluator.
