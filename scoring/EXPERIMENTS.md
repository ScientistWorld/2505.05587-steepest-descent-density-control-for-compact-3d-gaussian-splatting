# Experiment Overview

## compact_synthetic_splatting_seed7

Tests whether a Gaussian-splatting reconstruction system can preserve held-out color reconstruction quality while reducing the number of primitives and the corresponding rendering-cost proxy on deterministic scene seed 7.

## compact_synthetic_splatting_seed13

Repeats the same quality-versus-compactness measurement on deterministic scene seed 13. The purpose is to make the gym less brittle by requiring the compactness result to hold across more than one sampled scene initialization.
